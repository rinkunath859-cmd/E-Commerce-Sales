# 📊 E-Commerce Sales Data Cleaning & Business Analysis using SQL

## 📌 Project Overview

This project demonstrates end-to-end SQL data cleaning and business analysis using an E-Commerce Sales dataset.

The objective is to clean raw sales data, improve data quality, and generate business insights to support marketing, inventory management, and operational decision-making.

---

## Objectives

- Clean raw sales data
- Remove duplicates
- Handle missing values
- Standardize data
- Create derived columns
- Perform business analysis
- Generate actionable insights
